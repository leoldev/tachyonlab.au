Method

A loop you can hold.

Four moves, all of them on your hardware. The only thing that leaves is what you decide to send.

  1. CaptureEvery edit you make is written to a trace, in place, on this machine.
  2. CurateYou keep the traces that matter. The rest are dropped, by you.
  3. TrainA small adapter is trained from what you kept, while the base model stays untouched.
  4. DeleteThe adapter, the index and the traces go together. There is no remote copy to forget.
Trace

One correction, one line.

A trace is the difference between what the model said and what you wanted. It is a line in a local file, and it has no destination field.

Dear Maya, I hope this message finds you well. The deadline is Friday at noon.

Maya, the deadline is Friday at noon.

A trace is a line in a file you own. It is not a preference, and it is not a profile.
